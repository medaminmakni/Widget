# Widget Consulting — brand kit

**Concept:** a widget is a building block. The symbol is three dark tiles and one orange tile sliding into the empty slot: the piece we build for each client.

**Tagline:** We build the pieces your business runs on. · *Nous construisons les pièces sur lesquelles reposent les entreprises.*

## Files

| Folder | What's inside |
| --- | --- |
| `logo/` | Symbol (SVG + 512 px PNG) in color, reversed, on orange and monochrome; horizontal and stacked logos (SVG) |
| `colors/` | `tokens.json` and `tokens.css` with the palette and fonts |
| `social/` | Facebook profile picture (SVG + PNG), cover (1640×624) and launch post (1080×1080) as HTML pages |
| `brand-board.html`, `logo-system.html` | The brand board and logo system, open in a browser |
| `source/` | Original design canvas files (`light` = chosen brand A, `dark` = alternative B) |

The logo SVGs with the word "widget" load their font from Google Fonts. For print or offline use, install the fonts below or export the files to PDF/PNG from a browser.

To export the cover or post as PNG: open the HTML file in Chrome at 100% zoom, open DevTools (F12), right-click the top `<div>` and choose **Capture node screenshot**.

## Rules

- Use one orange piece per composition. Orange is the accent, not the background of everything.
- Keep clear space around the logo equal to one tile.
- Below 24 px, use the symbol alone, without the word.
- Do not stretch, recolor the dark tiles, rotate the logo, or add shadows and outlines to it.
- On photos, place the logo on a calm area, or use the symbol on an orange tile.
